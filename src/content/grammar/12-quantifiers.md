## 量詞概覽

量詞（Quantifiers）說明「多少」，使用時必須注意搭配的名詞是**可數（複數）**還是**不可數**。

| 量詞 | 可數複數 | 不可數 |
|------|---------|--------|
| many | ✓ | ✗ |
| much | ✗ | ✓ |
| few / a few | ✓ | ✗ |
| little / a little | ✗ | ✓ |
| several | ✓ | ✗ |
| numerous | ✓ | ✗ |
| some / any / no | ✓ | ✓ |
| all / most / most of | ✓ | ✓ |
| each / every | ✓ 單數 | ✗ |
| both | ✓ 複數 | ✗ |
| either / neither | ✓ 單數 | ✗ |

---

## each vs every

兩者都表示「每一個」，但有細微差別：

- **each** — 強調「個別地看每一個」，可用於兩個或以上，後接單數名詞
  - **Each** experiment was recorded and analyzed separately.
  - The researcher examined **each** sample individually.
  - **Each of** the participants **was** interviewed for thirty minutes.（of 後複數，動詞單數）

- **every** — 強調「所有、整體中的每一個」，用於三個或以上，後接單數名詞
  - **Every** participant must sign the consent form.
  - The team meets **every** Monday.
  - **Every** experiment **requires** careful documentation.

- ✓ **Each** of the two samples was tested.（兩個 → 用 each）
- ✓ **Every** country in the study had different results.（整體概念 → 用 every）
- ✓ **Every one of** the experiments failed.（強調全部每個，= each one）

## both / either / neither

這三個都專門用於**兩者之間**：

**both（兩個都）**：
- **Both** methods **were** tested and found to be effective.（both + 複數動詞）
- **Both** the experiment **and** the control **showed** similar results.
- **Both of** the researchers **agree** on the findings.

**either（兩者之一，或兩者都）**：
- You can use **either** method; both are acceptable.（兩個選其一）
- **Either** the temperature **or** the humidity **is** responsible.（either...or, 動詞看靠近的名詞）
- There is no consensus on **either** side of the debate.
- I don't think **either** approach is adequate.（在否定句中 = 兩個都不）

**neither（兩者都不）**：
- **Neither** conclusion **is** supported by the data.（neither + 單數動詞）
- **Neither** the experimental group **nor** the control group **showed** significant changes.（neither...nor, 動詞看靠近的名詞）
- **Neither of** the two hypotheses **was** confirmed.（neither of + 複數名詞，動詞單數）

:::tip
both → 複數動詞；either / neither → 單數動詞。
neither...nor / either...or 的動詞，看靠近動詞的那個名詞。
:::

## all / most / some / none

這四個後面接 of + 名詞時，動詞隨名詞的數和類型走：

**all（全部）**：
- **All** animals need water to survive.（all + 複數名詞，動詞複數）
- **All** of the evidence **points** to human activity.（evidence 不可數，動詞單數）
- **All** of the participants **were** given instructions.（participants 複數，動詞複數）
- **All** of the water **has** evaporated.（water 不可數，動詞單數）

**most（大多數）**：
- **Most** scientists **agree** that climate change is real.
- **Most of** the data **was** collected in urban areas.（data 不可數）
- **Most of** the researchers **have** published at least one paper.（researchers 複數）

**some（一些）**：
- **Some** studies **support** this hypothesis.（some + 複數名詞）
- **Some** evidence **suggests** a correlation.（some + 不可數名詞）
- **Some of** the results **were** surprising.（複數）
- **Some of** the funding **has** been redirected.（不可數）

**none（沒有任何）**：
- **None of** the experiments **produced** consistent results.（口語/慣常用法：動詞複數）
- **None of** the evidence **was** conclusive.（正式：none of + 不可數 → 單數）
- 注意：None 在正式學術英文中常視為單數；口語和非正式中可接複數動詞。

## some vs any vs no

| | 肯定句 | 否定句 | 疑問句 |
|---|---|---|---|
| **some** | 有一些（存在） | 少用 | 期待肯定答案時用 |
| **any** | 任何一個（不限定） | 沒有任何 | 一般疑問句 |
| **no** | （後接名詞）完全沒有 | — | — |

例句：
- The study found **some** interesting patterns.（肯定，有找到）
- Do you have **any** questions?（疑問，一般問法）
- Would you like **some** water?（疑問，期待對方說 yes）
- There isn't **any** evidence to support this.（否定）
- There is **no** evidence to support this.（= There isn't any，更直接）
- **Any** student who misses class will receive a warning.（肯定句中 = 任何）
- Researchers can use **any** of the three methods.（任何一種）

## 修飾量詞的副詞

可以在量詞前加副詞，強調程度：

- **almost** all — Almost all studies confirm this finding.（幾乎全部）
- **nearly** every — Nearly every participant completed the survey.（幾乎每個）
- **far** too many — There are far too many variables to control.（遠超過太多）
- **relatively** few — Relatively few studies have examined this.（相對很少）
- **significantly** more — This method requires significantly more resources.（顯著更多）
- **considerably** less — The new approach requires considerably less time.（相當少）
